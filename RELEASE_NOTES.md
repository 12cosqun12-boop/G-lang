# G 1.0 Release Notes

Initial public-ready package.

- Native Windows x86-64 compiler and PE32+ output
- Native Linux x86-64 compiler and ELF64 output
- Self-hosted compiler sources for both targets
- Direct machine-code generation without LLVM
- File I/O, command-line arguments, strings, arrays, pointers, functions, conditions and loops
- Common test suite
- G Tasks example application
