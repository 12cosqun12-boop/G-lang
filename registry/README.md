# Gate Registry

Gate is the package registry for the G programming language.

Current first-party packages:

- **gtabe 0.1.0** — cross-platform G window API
- **gmath 0.1.0** — integer math helpers
- **gstr 0.1.0** — string helpers
- **gargs 0.1.0** — command-line argument helpers
- **garray 0.1.0** — pointer-based integer array helpers

Each package lives at `registry/<name>/<version>/` with a `Gate.json` manifest and G sources.

Community publishing starts through the Gate website's Publish page, which creates a review request in this repository.
